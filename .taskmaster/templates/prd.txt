PRD: AI-Trader + open-trading-api 모의투자 통합

1. 배경/목표
- 기존 AI-Trader는 외부 시세 API와 로컬 시뮬레이션 매매를 사용함.
- 목표: KIS open-trading-api를 통해 시세/주문을 모의투자 환경으로 연결해 실제 API 흐름에 맞춘 테스트/운영 기반 마련.

2. 범위
- 포함: 해외주식 시세 조회(NAS/NASD)와 모의 매수/매도 주문, 잔고/체결 조회 연동.
- 제외: 실전투자 연결, 파생상품/국내주식, 웹소켓 실시간 시세 구독, 배치 리밸런싱 로직 변경.

3. 이해관계자
- 개발자: AI-Trader 코드 유지/배포 담당.
- 퀀트/전략가: 시세/주문 API로 백테스트-프론트테스트 전환 검증.
- 운영: 인증/계좌/레이트리밋 관리.

4. 가정/전제
- 모의 계좌와 app key/secret이 유효하게 발급되어 있고 kis_devlp.yaml에 입력 가능.
- 거래소는 NASD(나스닥) 기준; 티커는 KIS 규격(예: GOOGL) 그대로 사용.
- 주문은 지정가만 사용(ord_dvsn=00), 시장가는 모의 불가.

5. 기술 통합 설계(요약)
- 공통 인증: kis_auth.auth(svr="vps", product="01")로 모의토큰 획득, TREnv 저장.
- 시세: overseas_stock price API(`/uapi/overseas-price/v1/quotations/price`)를 래퍼로 노출해 현재가/거래량 등 반환.
- 주문: overseas_stock order API(`/uapi/overseas-stock/v1/trading/order`)를 래퍼로 노출해 buy/sell 실행. 모의 시 TR ID 자동 V-접두 처리.
- 잔고/체결: `inquire_balance`, `inquire_ccnl` 등 필요한 최소 조회만 노출(모듈화).
- 구성: `integrations/kis_client.py`(래퍼), 설정 로더, 에러/레이트리밋 공통 처리.

6. 기능 요구사항
- 시세 조회: 입력 티커 1개 → 현재가, 전일가, 등락률, 거래량 반환. 오류 시 명확한 메시지.
- 매수/매도: 티커, 수량, 지정가 입력 → 주문 접수 결과(원주문번호 포함) 반환. 파라미터 검증 필수.
- 잔고 조회: 환경에 따라 보유 종목/수량/평가금액 조회.
- 체결내역 조회: 기간/조건으로 체결/미체결 확인(최소 1일 단위).
- 리트라이/레이트리밋: TR_CONT=M 응답 시 후속 호출, smart_sleep 사용.

7. 비기능 요구사항
- 설정 분리: kis_devlp.yaml 경로/키 이름만 필요, 코드 내 하드코딩 금지.
- 로깅: API 호출 시작/성공/실패, 중요 파라미터만 로깅, 민감정보(mask).
- 오류 처리: 필수 파라미터 미입력시 ValueError; API 오류코드/메시지 전달.
- 테스트: 모의 환경 단위 테스트(시세, 주문 성공/실패 케이스)와 통합 스모크(시세→주문→잔고).

8. 인터페이스 설계(초안)
- `get_quote(symbol: str) -> Quote`: KIS price 결과를 표준 구조로 매핑(last, base, rate, volume).
- `buy(symbol: str, qty: int, limit: float) -> OrderResult`
- `sell(symbol: str, qty: int, limit: float) -> OrderResult`
- `get_balance() -> BalanceSnapshot`
- `get_fills(start: date, end: date) -> list[Execution]`
- 설정: `.env` 또는 yaml 경로 주입; broker 모드 플래그(`BROKER=kis`).

9. 마이그레이션/임팩트
- 시세 모듈: 기존 외부 API 호출 경로 → kis_client.get_quote로 교체.
- 매매 모듈: 로컬 시뮬레이션 → kis_client.buy/sell로 교체 (필요시 시뮬 모드 유지 토글).
- 데이터 포맷: 기존 price_tools의 buy/sell price 필드 사용부 정리 필요.

10. 리스크/대응
- 인증 실패/계좌 미입력: 초기 설정 체크리스트 제공, 실패 시 명확한 에러 반환.
- 레이트리밋/트래픽: smart_sleep, TR_CONT 처리, 불필요 반복 호출 최소화.
- 실계좌 오발주: 기본 모의 환경 고정, 실전 전환은 별도 플래그와 강제 확인 절차.
- 호가 제한: 지정가만 지원됨을 명시, 시장가 요구 시 에러.

11. 일정(제안)
- D1: kis_devlp.yaml 확인 및 kis_client 래퍼 뼈대 작성.
- D2: 시세/주문 래퍼 완성, 단위 테스트(모의).
- D3: AI-Trader 시세/매매 경로 연결, 스모크 테스트.
- D4: 문서화(README/사용 가이드) 및 운영 체크리스트.

12. 완료 기준
- 모의 환경에서 티커 1개 시세 조회 성공.
- 동일 티커 1주 매수/매도 모의 주문 성공(원주문번호 확인).
- 잔고/체결 조회가 주문 결과와 일치.
- 설정/사용 가이드 제공, 기본 테스트 스크립트 포함.
